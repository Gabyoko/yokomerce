# Diseño de referencia

Pantallas exportadas del diseño en Claude Design (HTML). Úsalas como referencia visual: colores, espaciados, textos y estructura.

- Este diseño usa una pastelería como ejemplo. Donde muestre "Tamaño" o "Dedicatoria" como fijos, manda `SPEC.md`: son opciones y campos extra creados por el dueño.
- Si se exporta una versión nueva del diseño, reemplaza los archivos de esta carpeta.

| --- | --- |

| Producto.dc.html | Detalle de producto |
